# 9. Desktop Interface

One window. No separate capability chatbots.

## Main screen (HUD)

- **Brand**: JARVIS wordmark / core orb as hero signal of the composition
- **Conversation stream**: primary dialogue
- **Composer**: text input + push-to-talk
- **Status rail**: voice state, current task, tool activity, device health
- **Permission modal**: blocks sensitive actions until answered
- **Notifications**: proactive alerts (non-spammy)
- **Panels** (same shell, tabs/drawers — not separate apps): Memory, Tasks, Logs, Devices, Settings

## Visual direction

Futuristic cyan HUD on deep space navy — usable contrast, not pure decoration. Motion: orb pulse, task progress sweep, permission modal entrance.

## Must show

Conversation, voice status, current task/progress, tool activity, memory access, notifications, permission requests, system/device status, results, logs/history, automation status.
